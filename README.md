# Szlakownik

Личная «mapa turystyczna» в виде PWA: карта с рельефом, официальные szlaki из OpenStreetMap, рисование маршрута с привязкой к тропам, профиль высот, длина/набор/время, GPX, офлайн-кэш карты. Без бэкенда — статические файлы.

## Что умеет

- **Базовые карты**: CARTO Voyager (чистая, читаемая — по умолчанию), OpenTopoMap (горизонтали), Esri World Topo, OSM, спутник Esri. По своему бесплатному ключу — Mapy.cz Turistická (лучшая для PL/CZ/SK) и Thunderforest Outdoors/Landscape (ключи вводятся в настройках).
- **Szlaki**: векторный слой прямо из OSM через Overpass — все маршруты `route=hiking/foot` включая локальные, пунктир цветом знака (osmc:symbol/colour), тап по тропе показывает название, ref, тип сети. Данные качаются по ячейкам (zoom 11) для просматриваемой области, хранятся в IndexedDB и работают офлайн; видны с zoom 10. Отдельно — веломаршруты (`route=bicycle/mtb`). Растровые слои waymarkedtrails оставлены как альтернатива.
- **Наложения**: тени рельефа (Esri World Hillshade, multiply), километровые отметки.
- **Маршрут**: «Рисовать» → тап по карте ставит точку. Точки можно таскать; тап по точке в режиме рисования удаляет её; тап по линии вставляет точку в середину. Undo. «По тропам» прокладывает отрезки по тропам через brouter.de (профиль hiking-mountain), иначе прямая пунктиром.
- **Трасса словами** (лупа в верхней панели): «Kuźnice – Hala Gąsienicowa – Zawrat – Morskie Oko» — каждая точка ищется в OSM через Nominatim рядом с текущим видом (ближайший к предыдущей точке вариант выбирается сам, остальные — в выпадающем списке), затем маршрут прокладывается по тропам через все точки. Разделители: тире, запятая, стрелка, новая строка; координаты «49.2323, 19.9812» тоже понимает. Название маршрута подставляется из текста.
- **Статистика**: длина, набор/сброс (с гистерезисом 4 м против шума SRTM), время по DIN 33466 (параметры в настройках).
- **Профиль высот**: с ховером — точка подсвечивается на карте. Высоты: из BRouter, для прямых отрезков — open-meteo.com.
- **Маршруты**: сохраняются в IndexedDB на устройстве; экспорт/импорт GPX.
- **GPS**: кнопка — показать позицию и следовать за ней; свайп карты выключает слежение.
- **Офлайн**: приложение целиком (service worker) + тайлы + ячейки szlaków. Всё, что просмотрено онлайн, остаётся в кэше; панель «Офлайн-карта» качает текущий экран или полосу ±1 км вдоль маршрута до выбранного zoom. Сохранённые маршруты офлайн показываются вместе с высотами.
- Языки: PL / RU / UK / EN (автоопределение, переключение в настройках). Тёмная тема по системе.

## Развернуть

Нужен любой статический хостинг **по HTTPS** (service worker, Cache Storage и геолокация работают только в secure context; `http://localhost` тоже считается secure — удобно для проверки).

```
szlakownik/
  index.html  app.js  app.css  sw.js  manifest.webmanifest
  vendor/leaflet.js  vendor/leaflet.css
  icons/
```

nginx:

```nginx
location /szlakownik/ {
    alias /var/www/szlakownik/;
    add_header Cache-Control "no-cache";      # чтобы sw.js и index.html обновлялись сразу
    types { application/manifest+json webmanifest; }
}
```

Caddy: `file_server` в нужном `handle_path` — больше ничего не нужно.

Локально: `cd szlakownik && python3 -m http.server 8080` → http://localhost:8080.

Подпапка работает (пути относительные, `scope: "./"` в манифесте). При обновлении кода подними `VERSION` в `sw.js` — старый shell-кэш удалится, страница покажет тост «доступна новая версия».

## На телефон

Открыть адрес → Chrome/Android: меню → «Добавить на главный экран»; iOS Safari: «Поделиться» → «На экран Домой». Установленная версия получает полноэкранный режим и более устойчивое хранилище (iOS может чистить данные неустановленных сайтов после ~7 дней без использования).

## Офлайн-кэш: как он устроен

- Тайлы запрашиваются `fetch`-ом с CORS и кладутся в Cache Storage (`szlakownik-tiles-v1`); Leaflet получает их как blob. Если сервер тайлов не отдаёт CORS-заголовки, слой показывается напрямую, но закэшировать его нельзя — панель «Офлайн» об этом предупредит.
- Ограничение на одну загрузку — 6000 тайлов (OpenTopoMap просит не выкачивать большие области). Ориентир: zoom 15 для долины/массива — несколько сотен тайлов, zoom 16–17 — тысячи.
- Объём кэша и кнопка очистки — в панели «Офлайн-карта». Запрашивается `navigator.storage.persist()`, чтобы браузер не вычищал кэш первым.
- Маршрутизация по тропам и высоты требуют сети; офлайн рисование даёт прямые отрезки, высоты подтянутся при появлении сети («Загрузить высоты»).

## Настроить под себя

- Источники тайлов — объект `SOURCES` в `app.js` (URL, поддомены, максимальный zoom, средний размер тайла для оценки; `key: 'mapy'|'tf'` — требует ключ из настроек).
- Векторные szlaki — класс `VectorTrails` (Overpass-запрос, размер ячейки `CELL_Z`, минимальный zoom `TRAIL_ZOOM`, цвета `OSMC_COLORS`). В консоли доступно `window.szlakownik = { map, trailsVec, bikeVec, settings }`.
- Формула времени — настройки в приложении (`flat`, `up`, `down`); сама формула — `computeStats()`.
- Профили BRouter — `<select id="selProfile">` в `index.html`.
- Иконки — `python3 tools/make-icons.py`; одно-файловая сборка — `node tools/build.mjs` → `dist/szlakownik-single.html` (всё инлайном, можно открыть прямо с диска; офлайн-shell при этом не работает, тайлы кэшируются только по HTTPS).
